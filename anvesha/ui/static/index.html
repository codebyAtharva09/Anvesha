What this console is

    
ANVESHA is a software-in-the-loop coarse Pointing-Acquisition-Tracking (PAT) simulator for mobile FSOC terminals, built for ISRO problem statement SIH26169. Every number and image on the LIVE tab comes from the running engine: the virtual camera image is rendered by the simulator, detection/estimation/control run on that image only, and ground truth is used only to compute the error metrics shown.

    
Loop

    
virtual camera → noise-adaptive matched filter + CFAR → CNN verifier → gated association → IMM estimator (gimbal frame, IMU input, jitter-aware noise) → PAT supervisor → belief-driven search / predictive control → rate-limited gimbal → camera.

    
Honesty notes

    
  • This is a simulation prototype, not flight software.
  • Image-plane error includes camera jitter, which a coarse gimbal cannot correct; LOS error excludes it. Both are logged.
  • The beacon marker on the world view is simulator truth shown for the operator only; it is never used by the tracker.
